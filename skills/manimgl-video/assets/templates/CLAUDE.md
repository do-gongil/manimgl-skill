# CLAUDE.md

## What this is

ManimGL (3Blue1Brown's Manim, `from manimlib import *` — **not** Manim Community
Edition) explainer videos: {{description}}. On-screen text is {{language}}.

One self-contained scene file per topic; rendered files land in `videos/`.
Use the `manimgl-video` skill for ManimGL API work and its
`references/patterns.md` for how a scene is structured.

## Commands

```bash
python -m manimlib scene.py SceneName          # interactive preview (fast loop)
python -m manimlib scene.py SceneName -w -l    # low-res mp4, to judge timing
python -m manimlib scene.py SceneName -w --hd  # 1080p, only when timing is final
```

`python -m manimlib` is used instead of `manimgl` because pip's Scripts dir
may not be on PATH. There is no test suite; a snapshot is the check:

```bash
python <plugin>/skills/manimgl-video/assets/snapshot.py scene.py SceneName --list   # number the beats
python <plugin>/skills/manimgl-video/assets/snapshot.py scene.py SceneName 4 9 14   # frames/SceneName_004.png ...
```

Look at every frame before handing a scene over.

## Environment

`custom_config.yml` (generated by `doctor.py --write-config`, machine-specific,
gitignored) encodes the platform workarounds. Keep it ASCII-only: manimlib reads
it with the locale codec. Rerun `doctor.py` if a render fails for a reason that
is not the scene code.

## Scene conventions

- `common.py` provides `txt()` and `tex()`. Never call bare `Text`/`Tex`: the
  font and the amsmath preamble are decided there once.
- `construct()` is a list of calls to one method per beat; state passes between
  beats as `self.<name>` attributes set at the end of each. Define the beat
  methods in the order `construct()` calls them.
- Numbers on screen come from real computation, not hardcoded shapes. Pure
  functions get an `if __name__ == "__main__":` block with a few asserts that
  runs without manimgl.
- `ReplacementTransform` leaves its target in the scene — remove copies and add
  the canonical object afterwards.
- Pass an explicit step in `x_range` to `get_graph` for anything with more than
  a few oscillations across the axis.
- `ponytail:` comments mark deliberate simplifications and name the upgrade path.
